# Rooted AI Website

## Project Overview
Marketing website for Rooted AI — a company deploying private, on-premise AI infrastructure (local LLMs, RAG systems, Docker stacks) for businesses, libraries, and non-profits.

## Core Value Proposition
"Your data never leaves your building." — Local AI vs cloud AI.

## Branding
- **Name**: Rooted AI
- **Tagline**: "Private, powerful AI infrastructure built for your organization. No cloud required."
- **Palette**: Forest green primary (#2D5016 range → `--primary`), warm cream backgrounds (#F5F0E8 → `--background`), charcoal text (#2C2C2C → `--foreground`), amber accent (#C17F24 → `--accent`)
- **Theme**: Light mode default, earthy/grounded aesthetic
- **Fonts**: DM Sans (body), Plus Jakarta Sans (display), JetBrains Mono (mono)

## Pages
1. **Home** (`/`) — Hero, value props, sector preview, how it works, trust badges, CTA
2. **Solutions** (`/solutions`) — For Businesses + For Libraries & Non-Profits
3. **How It Works** (`/how-it-works`) — 4-step process: Assess → Provision → Deploy → Support
4. **Use Cases** (`/use-cases`) — 5 scenarios (library, HR, doc search, government, schools)
5. **Trust & Security** (`/security`) — Why local is safer, comparison table
6. **Contact** (`/contact`) — Lead gen form with email notifications
